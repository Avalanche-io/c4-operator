Collapse to aggregate

The same sh040 data four ways. Any container collapses to one block whose fill is the aggregate of everything inside it and upstream of it, by work where the estimate exists: green done, a blue sliver running with green rising inside, an orange tick if anything inside is retrying, a red tick if anything failed, a dashed red outline if any of it is projected late. An expanded container keeps its aggregate as a thin gauge on its edge so the fill is never read as rows.

1 · expanded
every batch open, every stage visible
2 · upstream folded
sim and render fold into each frame’s aggregate block
3 · batches collapsed (default)
open only where something needs attention
4 · shot collapsed
one block: the shot and everything upstream
