## c4_approve_capacity

Approve the burst capacity request waiting in a pool. This provisions paid capacity; check c4_capacity_and_cost first for its cost and the jobs it is for.

Input:

```json
{
  "additionalProperties": false,
  "properties": {
    "pool": {
      "description": "the burst pool whose waiting request to approve",
      "type": "string"
    }
  },
  "required": [
    "pool"
  ],
  "type": "object"
}
```

## c4_diff_views

The files that differ between two views (C4 IDs) of a project: added, modified and removed paths with sizes and IDs, computed from directory records without a checkout. Use it to choose which CI targets a change affects.

Input:

```json
{
  "additionalProperties": false,
  "properties": {
    "from": {
      "description": "the earlier view's C4 ID",
      "type": "string"
    },
    "limit": {
      "description": "most changes to return (default 1000)",
      "type": "integer"
    },
    "project": {
      "description": "the project whose store holds both views",
      "type": "string"
    },
    "to": {
      "description": "the later view's C4 ID",
      "type": "string"
    }
  },
  "required": [
    "project",
    "from",
    "to"
  ],
  "type": "object"
}
```

```json

  "additionalProperties": false,
  "properties": {
    "include_units": {
      "description": "also list units (at most 500)",
      "type": "boolean"
    },
    "name": {
      "description": "the job's name",
      "type": "string"
    },
    "namespace": {
      "description": "the job's namespace",
      "type": "string"
    },
    "unit_state": {
      "description": "with include_units, only units in this state (queued, running, retrying, succeeded, failed, held, blocked)",
      "type": "string"
    }
  },
  "required": [
    "namespace",
    "name"
  ],
  "type": "object"
}
```

```json

    "at_risk_only": {
      "description": "only jobs projected to miss their deadline",
      "type": "boolean"
```

## c4_read_book

The farm's history, newest last: units captured and failed on which node, retries, expansions, yields and resumes, capacity requested, approved and provisioned, and every hold, boost, deadline and requeue a person or agent made, each with who did it, which entity signed it and the C4 ID of its signed record. Filter to one job with namespace and name. Use it to answer why a unit retried, why a run yielded or who moved a deadline.

Input:

```json
{
  "additionalProperties": false,
  "properties": {
    "limit": {
      "description": "newest entries to return, 1 to 1000 (default 50)",
      "type": "integer"
    },
    "name": {
      "description": "with namespace, only this job's entries",
      "type": "string"
    },
    "namespace": {
      "description": "with name, only this job's entries",
      "type": "string"
    }
  },
  "type": "object"
}
```

## c4_verify_custody

Every signed record between a file a job wrote and where its inputs came from, each verified with its signer: the task record (signed by the node that ran the unit), each input's resolution (the controller), the input's origin (an import or ingest signed by a workload, or the upstream job's record signed by the queue, with its scheduling decisions, the HUD and MCP actions on it, its own task records and inputs), and the job's own record. Reports verified (every record checks out and was signed by whom the farm's policy wants), complete (no step lacks a record), the distinct signers, and any gaps.

Input:

```json
{
  "additionalProperties": false,
  "properties": {
    "name": {
      "description": "the job's name",
      "type": "string"
    },
    "namespace": {
      "description": "the job's namespace",
      "type": "string"
    },
    "path": {
      "description": "a file the job wrote, relative to its output view, for example renders/sh010/sh010.1039.exr",
      "type": "string"
    },
    "unit": {
      "description": "or a unit index, for the unit's own record",
      "type": [
        "null",
        "integer"
      ]
    }
  },
  "required": [
    "namespace",
    "name"
  ],
  "type": "object"
}
```
